Resume

📄 Update Resume

Upload a new PDF and it will replace your current Vinay-Resume.pdf in the GitHub repository.

Used only for this upload. It is not saved in localStorage.

ℹ️ How it works

  1. Select your latest resume PDF.
  2. Enter a GitHub token with repository Contents: Read and write permission.
  3. Click Replace Resume.
  4. The existing file at the same path is overwritten with the new PDF.
  5. GitHub Pages will publish the updated resume after the site rebuilds.

Important: Keep the same file path (Vinay-Resume.pdf) so your portfolio's Download CV button continues to work.
